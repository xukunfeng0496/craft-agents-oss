## v0.7.1 更新内容

### 新功能
- **浏览器 UI 国际化**：浏览器标签页、工具栏、空状态等所有组件接入 i18n，支持中英文切换
- **Session 产物输出**：会话产生的文件自动路由到 session 专属输出文件夹

### 修复
- **技能市场预览异常**：修复技能市场中技能预览和网络请求错误
- **文件浏览器信任路径**：修复 session 文件浏览器受信路径判断问题
- **大文件附件上传**：修复本地大文件附件上传失败的问题
- **文件路径验证策略**：拆分文件路径验证策略，允许从任意本地路径选择文件附件
- **浏览器提示文字乱码**：修复浏览器空状态提示文字中的字符损坏问题
- **语言设置统一**：统一应用语言为单一来源，默认中文

### 改进
- **Windows 安装包优化**：优化 Windows 安装包打包配置，减小体积和提升安装速度
- **Session 运行时目录**：使用工作目录作为 session 运行时根路径
- **CI 自动更新配置**：生产构建中内置 AUTO_UPDATE 环境变量，更新服务端地址切换为 HTTP
