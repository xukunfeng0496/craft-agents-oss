# Superpowers

An agentic skills framework & software development tool for Claude Code. Provides reusable techniques, patterns, tools, and reference guides for professional development.

## What It Is

Superpowers is a modular skills framework that transforms AI from a "code typist" into a rigorous, efficient engineering partner. It provides:

- **20+ Battle-Tested Skills**: Proven techniques for real-world development
- **Core Capabilities**: TDD (Test-Driven Development), debugging, collaboration patterns
- **Reusable Patterns**: Feature planning, issue debugging, code review, and more
- **Community-Driven**: Extensible framework with community contributions

## Key Skills

### Development Workflow
- **TDD/BDD**: Test-driven and behavior-driven development practices
- **Feature Planning**: Structured approach to planning and implementing features
- **Code Review**: Systematic code review methodology
- **Refactoring**: Safe, systematic code improvement

### Debugging
- **Issue Debugging**: Structured problem-solving approach
- **Root Cause Analysis**: Finding and fixing underlying issues
- **Performance Profiling**: Identifying and resolving bottlenecks

### Collaboration
- **Pair Programming**: Effective collaboration patterns
- **Documentation**: Writing clear, useful documentation
- **Git Workflow**: Best practices for version control

### Architecture
- **Design Patterns**: Applying proven patterns appropriately
- **System Design**: Architecting scalable systems
- **Code Organization**: Structuring projects for maintainability

## When to Use
