# CVTE 企业版

Work Agents CVTE 企业版 —— 基于上游 v0.10.3 重基线的内网增强版。

## 零配置接入
- 预置 CVTE 网关（token.cvte.com），安装即用。
- 「CVTE 门户登录」一键获取你的个人 API Key（按人配额、可审计）。
- 智能路由模型 **CVTE-AUTO** 自动选择最优模型；另提供 DeepSeek、GLM、Qwen 等。

## 企业内网
- 会话分享走内网查看器，企业数据不外发公网。
- 技能来自内网技能库与预置技能。
- 全程内网直连。

## 其他
- 简体中文界面与 CVTE 品牌。
- Windows 内置 Git / Python，免额外安装即可使用智能体能力。
