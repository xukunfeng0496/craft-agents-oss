# 0.10.307

## 修复
- 网关连接默认使用 Anthropic 协议；自动纠正历史遗留的协议/命名不一致（连接显示为「CVTE Gateway」）。
- 模型多模态标注修正：Qwen3.7 Max 为纯文本（CVTE-AUTO、Qwen3.7 Plus 支持图像）。
- 配置 API Key 时先校验网关连通与协议一致再保存。
- 门户登录在内网密钥服务不可达时给出清晰提示（不再显示 "fetch failed"）。
- 「最新动态」改为展示本企业版的更新记录（不再是上游更新）。

## 变更
- 移除应用内技能市场，改用内网技能库 + 预置技能。
- 安全加固：网关密钥中继支持可吊销的管理凭据；启用代理时自动旁路企业内网域。
