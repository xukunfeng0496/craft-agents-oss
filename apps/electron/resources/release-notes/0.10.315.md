# 0.10.315

## 新增
- 正式接入 CVTE 生产统一门户登录（home.cvte.com）：一键完成登录并自动获取你的个人 API Key（按人配额、可审计）。
- 门户登录回调直接唤起客户端：授权完成后自动切回 Work Agents，不再停留在浏览器页面。
- 故障自动上报：智能体出错时自动上报至内网监控用于排障（已脱敏，不含密钥 / Token / 凭据）。

## 修复
- 修复使用 Anthropic 协议手动配置 API Key 时，连通性检测可能误报失败的问题（连接其实可用，现已稳定通过）。
- 智能体任务出错时给出具体错误信息，不再是空白的「Unknown Error」，便于定位与重试。
- 手动配置 API Key 后的连通性检测改用 **CVTE-AUTO** 智能路由模型，不再误用不可用的官方模型导致误判。

## 变更
- 移除内置的共享兜底密钥：接入改为「门户登录自动取个人 Key」或手动配置，更安全、可审计。
- 启用系统代理时自动旁路企业内网域（新增 *.seewo.com），避免内网服务被代理拦截。
