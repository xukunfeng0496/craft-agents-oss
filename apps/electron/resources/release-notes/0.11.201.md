# 0.11.201

本次为大版本重基线：在保留 CVTE 企业能力（统一门户登录、按人配额、内网技能市场、内网 OTA）的前提下，整体升级到上游 0.11.2。

## 新增
- **项目（Projects）**：工作区内可创建「项目」，把会话、资料和上下文归到一起。会话绑定项目后自动继承项目工作目录，并把项目资料清单与 `MEMORY.md` 注入系统提示，开场即懂业务背景。
- **看板任务板（Beta）**：会话与任务以卡片形式呈现在可拖拽的看板上，支持按项目自定义列、列颜色与「拖入即改状态」。任务独立于聊天存在，可编辑、可重跑；复杂任务可拆成依赖 DAG，由 Conductor 编排子会话按依赖顺序执行，中断后可续跑。
- **智能体可自建任务**：智能体可通过 `create_task` 直接在看板上创建未启动的任务（标题、描述、验收标准、数据源、技能、模型、工作目录）。
- **后台子智能体跨轮存活**：后台任务不再因发起它的那一轮结束而被杀掉；完成后会主动唤醒会话呈现结果，输入框上方有运行中任务胶囊。
- **会话可在任意两个工作区间互传**，含远程↔本地、本地↔本地。

## 改进
- **模型阵容更新**：新增 Claude Sonnet 5（1M 上下文、自适应思考）；OpenAI GPT-5.6（Luna / Terra / Sol）；z.ai GLM-5 系列。Max 思考档位对支持的模型原生下发，不再降级到 XHigh。
- **Claude Agent SDK 升级到 0.3.197**，Pi SDK 升级到 0.80.6：修掉长上下文场景下 SSE 20 秒超时截断，长上下文计费更准确。
- **配置自动备份**：启动时快照 `config.json` 并保留最近三份，配置写坏可回滚。
- **空输入框按 ↑** 可取消当前运行并把上一条提示词取回来继续编辑。
- 界面文案全量本地化补齐（含权限模式选择器、浏览器工具栏窗口）。

## 修复
- 会话标题跟随「外观 → 语言」设置生成；未设置语言时按你实际书写的语言自动判断，不再一律英文。
- 智能体回复过程中排队发送的消息，不会再把进行中的回复挤到新消息下方；也不会让智能体误以为上一条已完成的回复被打断。
- macOS 本地网络权限声明补齐，局域网 Ollama / MCP 服务在授权后可用。
- 侧边栏超长标签会截断，不再撑破会话列表。
- 自动更新新增常开诊断日志，便于排查「下载完却没装上」。
