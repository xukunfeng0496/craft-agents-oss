# v0.5.4 — Windows Polish & Scheduled Prompts

Bug fixes and improvements for Windows users, plus a new scheduled prompts feature.

---

## New Features

- **Scheduled Prompts** — Schedule recurring prompts to run automatically at set times. Create, edit, and delete schedules from the sidebar panel. Useful for daily standups, periodic summaries, or any repeating task.

## Bug Fixes

- **Windows: "Finder" label replaced with "Explorer"** — Menu items and overlays that previously showed macOS-specific "Show in Finder" / "在访达中显示" now correctly display "Show in Explorer" / "在文件资源管理器中显示" on Windows.
- **Windows: App title fixed** — The app window title now shows "Work Agents" consistently across all platforms.
- **UI freeze when sending Office files** — Dragging or attaching `.docx`, `.xlsx`, `.pptx` files no longer freezes the chat input while the attachment is being processed.
- **User message shown immediately** — Sent messages now appear in the chat instantly, before attachment storage completes, so the UI feels more responsive.

## Improvements

- **New models: CVTE-AUTO and GLM-5** — Added CVTE-AUTO and GLM-5 to the model selector. Removed deprecated Sonnet 4.5 and 4.6 entries.
- **Auto-update reliability** — Fixed installation and UI issues with the auto-updater on macOS (multi-arch support for arm64 + x64).
