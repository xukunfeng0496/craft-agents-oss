# v0.6.0 — Browser Tools & Streaming Reliability

This release brings native browser tooling into Work Agents and improves reliability across long-running sessions.

---

## New Features

- **Built-in browser tools** — Agents can now open a real browser window, navigate pages, inspect accessibility structure, click elements, fill inputs, take screenshots, and review console or network activity without external browser setup.
- **Browser access in chat** — Added a browser tab strip and quick-open entry in the chat UI so browser windows are easier to launch and switch during a session.
- **Claude browser tool support** — `browser_tool` is now wired into the Claude agent flow and allowed in safe mode.

## Bug Fixes

- **Browser pane stability** — Fixed browser IPC wiring, preload routing, initial show behavior, and localized empty-state handling.
- **Session recovery and attachments** — Improved interrupted session recovery and attachment follow-up reliability.
- **Title and input polish** — Fixed Codex title generation alignment with the shared prompt flow and corrected structured input height sync issues.

## Improvements

- **Streaming performance** — Reduced redundant session work, narrowed renderer updates during streaming, and stabilized long-running turns.
- **Platform compatibility** — Windows now prefers the bundled MinGit shell for Git Bash checks, and macOS gets per-request Claude runtime fallback behavior.
- **UI polish** — Reduced repeated workspace icon lookups and refined browser-related UI components.
