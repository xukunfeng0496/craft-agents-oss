# v0.4.8 — LLM 工具与插件修复

---

## 新功能

- **`call_llm` 工具** — 调用辅助 LLM 执行专项子任务，如摘要生成、分类和结构化提取。支持全部三种后端：Claude、Codex 和 Copilot；API Key（完整功能）和 OAuth（基础功能）均可使用。支持并行调用、文件附件和结构化 JSON 输出。

## Bug 修复

- **插件名称解析** — 当工作区目录名与 SDK 插件名不一致时，技能无法加载。现在会直接读取 `.claude-plugin/plugin.json` 中的实际插件名。
- **技能热重载** — 添加工作区技能后，全局和项目级技能会消失，直到重启才恢复。所有重载路径现在统一使用 `loadAllSkills`，始终返回完整的三层列表。
- **Codex 事件队列竞态条件** — 当异步 `item/completed` 处理器仍在运行时触发 `turn/completed`，可能导致工具结果或助手文本丢失。现在通过延迟队列完成直到所有处理器结束来修复。

## 内部变更

- Copilot `runMiniCompletion` 现已可用 — 在 Copilot 后端支持标题自动生成
- Copilot 事件适配器现在会过滤推理/意图事件
- TurnCard 活动行中展示 `call_llm` 的模型标识
