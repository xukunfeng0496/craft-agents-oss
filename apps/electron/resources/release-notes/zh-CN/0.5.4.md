# v0.5.4 — Windows 优化与定时提示

针对 Windows 用户的修复与改进，以及新增定时提示功能。

---

## 新功能

- **定时提示** — 支持设置定时任务，在指定时间自动发送提示。可在侧边栏面板中创建、编辑和删除定时计划，适用于每日站会、定期摘要等重复性任务。

## Bug 修复

- **Windows：文件管理器标签修正** — 菜单和浮层中原本显示 macOS 专属的"在访达中显示"，现在在 Windows 上正确显示为"在文件资源管理器中显示"。
- **Windows：应用标题修正** — 应用窗口标题在所有平台上统一显示为"Work Agents"。
- **发送 Office 文件时界面卡顿** — 拖入或附加 `.docx`、`.xlsx`、`.pptx` 文件时，聊天输入框不再因附件处理而冻结。
- **用户消息立即显示** — 发送的消息现在会在附件存储完成前立即显示在聊天中，界面响应更流畅。

## 改进

- **新增模型：CVTE-AUTO 和 GLM-5** — 模型选择器中新增 CVTE-AUTO 和 GLM-5，移除已废弃的 Sonnet 4.5 和 4.6。
- **自动更新稳定性** — 修复了 macOS 自动更新程序的安装和 UI 问题（支持 arm64 + x64 多架构）。
