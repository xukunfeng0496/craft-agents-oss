# v0.6.0 — Browser 工具与流式稳定性增强

这个版本将原生浏览器工具正式带入 Work Agents，同时提升了长时间会话的稳定性。

---

## 新功能

- **内置 Browser 工具** — Agent 现在可以直接打开真实浏览器窗口，导航页面、读取无障碍结构、点击元素、填写输入框、截图，并查看控制台和网络活动，无需额外浏览器集成。
- **聊天页浏览器入口** — 聊天界面新增浏览器标签栏与快捷打开入口，更方便在会话过程中启动和切换浏览器窗口。
- **Claude Browser Tool 支持** — `browser_tool` 已接入 Claude Agent 流程，并支持在 safe mode 下使用。

## Bug 修复

- **浏览器窗口稳定性** — 修复 browser IPC 连接、preload 路由、首次显示行为，以及空状态本地化相关问题。
- **会话恢复与附件** — 提升中断 session 恢复和附件 follow-up 的可靠性。
- **标题与输入体验** — 修复 Codex 标题生成与 shared prompt 流程不一致的问题，并修正 structured input 高度同步异常。

## 改进

- **Streaming 性能** — 减少冗余 session work，缩小流式输出期间的 renderer 更新范围，并提升长时间 turn 的稳定性。
- **平台兼容性** — Windows 优先使用 bundled MinGit shell 做 Git Bash 检查，macOS 增加 Claude runtime 的 per-request fallback。
- **界面细节打磨** — 减少重复 workspace 图标查找，并优化 browser 相关 UI 组件细节。
