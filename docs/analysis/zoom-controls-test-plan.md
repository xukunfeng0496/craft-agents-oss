# 图片缩放控件功能测试方案

**功能：** 图片和 Mermaid 图表的缩放/平移功能
**分支：** feat/zoom-controls
**测试日期：** 2026-03-08

---

## 🎯 测试目标

验证从上游 v0.7.0 合并的缩放控件功能在 CVTE fork 中正常工作，包括：
- 缩放控件 UI 显示正确
- 所有交互方式（鼠标、触控板、键盘）正常工作
- 图片和 Mermaid 图表都支持缩放
- 无性能问题或控制台错误

---

## ✅ 快速测试清单（5 分钟）

### 1. 图片预览缩放测试
- [ ] 打开任意图片预览
- [ ] 点击放大按钮 (+) → 图片放大
- [ ] 点击缩小按钮 (-) → 图片缩小
- [ ] 点击百分比下拉菜单 → 选择 50% → 图片缩放到 50%
- [ ] 点击"适应窗口"按钮 → 图片适应窗口大小
- [ ] 点击重置按钮 → 图片恢复 100%

### 2. 鼠标交互测试
- [ ] 鼠标滚轮向上滚动 → 图片放大（光标位置保持不变）
- [ ] 鼠标滚轮向下滚动 → 图片缩小
- [ ] 点击并拖拽图片 → 图片平移
- [ ] 双击图片 → 重置到 100%

### 3. 键盘快捷键测试
- [ ] 按 `Cmd/Ctrl +` → 图片放大
- [ ] 按 `Cmd/Ctrl -` → 图片缩小
- [ ] 按 `Cmd/Ctrl 0` → 重置到 100%

### 4. Mermaid 图表测试
- [ ] 打开任意 Mermaid 图表预览
- [ ] 验证缩放控件显示
- [ ] 测试放大/缩小按钮
- [ ] 测试鼠标滚轮缩放
- [ ] 测试拖拽平移

### 5. 基本检查
- [ ] 打开开发者工具 → 无控制台错误
- [ ] 缩放操作流畅，无卡顿
- [ ] 关闭预览 → 重新打开 → 缩放状态重置

## 📋 详细测试步骤

### 测试 1：图片预览基本功能

**步骤：**
1. 启动应用：`bun run electron:dev`
2. 创建或打开一个会话
3. 上传或生成一张图片
4. 点击图片打开预览

**预期结果：**
- ✅ 图片预览窗口打开
- ✅ 右上角显示缩放控件（+、百分比、-、重置按钮）
- ✅ 初始缩放为 100%

---

### 测试 2：缩放控件 UI

**步骤：**
1. 在图片预览中，观察缩放控件
2. 点击百分比下拉菜单

**预期结果：**
- ✅ 下拉菜单显示预设选项：25%, 50%, 75%, 100%, 150%, 200%, 400%
- ✅ 当前缩放级别有复选标记
- ✅ "适应窗口"选项显示
- ✅ UI 样式与应用整体风格一致

**测试各预设级别：**
- [ ] 选择 25% → 图片缩小到 1/4
- [ ] 选择 50% → 图片缩小到 1/2
- [ ] 选择 100% → 图片恢复原始大小
- [ ] 选择 200% → 图片放大到 2 倍
- [ ] 选择 400% → 图片放大到 4 倍

---

### 测试 3：鼠标滚轮缩放

**步骤：**
1. 将鼠标光标放在图片的左上角
2. 向上滚动鼠标滚轮
3. 观察图片缩放行为

**预期结果：**
- ✅ 图片以光标位置为中心放大
- ✅ 光标下的图片区域保持在光标位置（光标锚定）
- ✅ 百分比显示实时更新
- ✅ 缩放平滑，无跳跃

**重复测试：**
- [ ] 光标在图片中心 → 滚轮缩放 → 中心保持不变
- [ ] 光标在图片右下角 → 滚轮缩放 → 右下角保持不变
- [ ] 向下滚动 → 图片缩小
- [ ] 缩放到最小 (25%) → 继续滚动 → 不再缩小
- [ ] 缩放到最大 (400%) → 继续滚动 → 不再放大

---

### 测试 4：触控板捏合缩放（如果有触控板）

**步骤：**
1. 在图片预览中
2. 使用触控板双指捏合手势

**预期结果：**
- ✅ 双指分开 → 图片放大
- ✅ 双指合拢 → 图片缩小
- ✅ 缩放行为与鼠标滚轮一致

---

### 测试 5：点击拖拽平移

**步骤：**
1. 将图片放大到 200%
2. 点击图片并按住鼠标左键
3. 拖动鼠标

**预期结果：**
- ✅ 光标变为 `grab` 图标
- ✅ 按住时光标变为 `grabbing` 图标
- ✅ 图片跟随鼠标移动
- ✅ 释放鼠标后图片停留在新位置
- ✅ 平移流畅，无延迟

**边界测试：**
- [ ] 拖拽到边缘 → 图片可以移出视口
- [ ] 拖拽回来 → 图片可以移回视口中心

---

### 测试 6：双击重置

**步骤：**
1. 将图片缩放到任意非 100% 的级别（如 200%）
2. 平移图片到偏离中心的位置
3. 双击图片

**预期结果：**
- ✅ 图片缩放重置到 100%
- ✅ 图片位置重置到居中
- ✅ 重置动画平滑

---

### 测试 7：键盘快捷键

**步骤：**
1. 在图片预览中
2. 按下各个快捷键

**测试清单：**
- [ ] `Cmd +` (macOS) 或 `Ctrl +` (Windows/Linux) → 放大 25%
- [ ] `Cmd =` (macOS) 或 `Ctrl =` (Windows/Linux) → 放大 25%
- [ ] `Cmd -` (macOS) 或 `Ctrl -` (Windows/Linux) → 缩小 25%
- [ ] `Cmd 0` (macOS) 或 `Ctrl 0` (Windows/Linux) → 重置到 100%
- [ ] 连续按 `Cmd +` 多次 → 逐步放大
- [ ] 连续按 `Cmd -` 多次 → 逐步缩小

**预期结果：**
- ✅ 所有快捷键响应正确
- ✅ 快捷键与按钮功能一致
- ✅ 工具提示中显示快捷键提示

---

### 测试 8："适应窗口"功能

**步骤：**
1. 打开一张大图片（大于窗口尺寸）
2. 点击"适应窗口"按钮

**预期结果：**
- ✅ 图片缩放到适应窗口大小（90% 填充）
- ✅ 图片居中显示
- ✅ 保持图片宽高比

**测试不同尺寸：**
- [ ] 横向图片 → 适应宽度
- [ ] 纵向图片 → 适应高度
- [ ] 小图片 → 不放大超过 100%

---

- ✅ 与双击效果相同
