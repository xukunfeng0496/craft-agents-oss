- **沙箱 e2e**（C1/C2/C3/C5/R1/R6/R8）：CDP 驱动打包 app，隔离 `~/.workagent`（见记忆 [[e2e-sandbox-playbook]]）。注意：必须种真实数据、单实例锁、代理坑。
- **真机/scheme**（R7/C2 回焦）：app 装 /Applications 并运行一次注册 scheme，`open workagents://…` 验唤起。
- **relay live**（R2/R3）：对 portal-key-relay.test.seewo.com（已切 home）走真实 home 登录 token → /api/resolve-key。✅ 端到端已实测通过（userId=968、无 PKCE、loopback 回调被接受）。
